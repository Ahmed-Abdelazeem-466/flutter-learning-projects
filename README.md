## What is not included

- **The `ios`, `macos`, `linux`, `windows` and `web` platform folders.** They are generated files. Run `flutter create .` inside a project folder to recreate them. The Android code is included.
- **Private Firebase configuration** for `sams-chat`. See that project's README to connect your own Firebase project.
- **Audio and image assets** of `toku-language-app` and `note-player`. The code is here, but the apps will not play sounds or show images until you add your own files.
