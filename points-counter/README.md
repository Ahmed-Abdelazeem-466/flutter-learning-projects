# Points Counter

A simple Flutter app that keeps the score of two basketball teams. Each team has +1, +2 and +3 buttons, and a reset button clears both scores.

**Origin:** a practice project from learning Flutter basics (state with `setState`, rows and columns, buttons).

## Run

```
flutter pub get
flutter run
```

## Notes

- The whole app is in `lib/main.dart`.
- The button code is repeated for each team. Extracting it into one reusable widget would be the next improvement.
